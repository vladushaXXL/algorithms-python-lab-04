# Лабораторная работа №4 — Генераторы и встроенные функции Python (Вариант 13)

## Описание
Настольное приложение на Python с графическим интерфейсом на **PySide6**, реализующее задачи 13 варианта лабораторной работы №4 на уровне сложности **Well-done**:
1. Генератор модулей целых чисел в диапазоне `[a; b]` (`a < b`) с универсальным выводом до 4 первых значений.
2. Бесконечная функция-генератор случайных паролей длиной 12 символов.
3. Попарное перемножение двух списков целых чисел с помощью `zip` и `map` с извлечением первых трёх результатов через `next`.
4. Параллельная версия генератора паролей (`ProcessPoolExecutor`) с замером ускорения относительно последовательной реализации.

## Инструкции по запуску

### 1. Установка зависимостей

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
### 2. Запуск графического приложения
Bash
python main.py
### 3. Запуск автотестов

pytest -v

## Краткая справка
Вкладка «Задача 1: Модули»: введите целые числа a и b (a < b) и нажмите «Сгенерировать».

Вкладка «Задача 2: Пароли»: выберите нужное количество паролей (по умолчанию 5) и нажмите «Сгенерировать пароли».

Вкладка «Задача 3: zip + map»: введите два списка целых чисел через пробел (минимум по 3 числа в каждом) и нажмите «Вычислить первые 3 произведения».

Вкладка «Well-done: Бенчмарк»: задайте объём генерации (рекомендуется от 300 000 паролей) и число процессов, затем нажмите «Запустить бенчмарк» для сравнения времени работы.
